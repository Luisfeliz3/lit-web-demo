BEHIND THE BUILD

Built by Luis Feliz

A nightlife discovery app built with React Native, Expo, TypeScript, and Firebase, with native Apple Maps on iPhone and MapKit JS on the web.

React NativeExpoTypeScriptFirebaseApple MapKit
  • Shared occupancy rules drive pin colors and venue status.
  • The real app uses a 100-meter check-in geofence and expiring posts.
  • This public demo keeps all simulated activity in browser memory.
